Markdown Parsing Debugger

This tool helps debug markdown parsing issues, particularly extra spacing between lines. Use the interactive debugger below or examine the test cases to identify problems.

How to Use

  • Enter markdown in the input area to see how it gets parsed
  • Check the "Contains markdown" indicator to see if markdown formatting is detected
  • Examine the raw HTML output to see exactly what's generated
  • Use the test cases below to identify specific spacing issues
  • Add ?markdown-debug to any FileSurf page to enable the debugger
