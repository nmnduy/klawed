Goal: choose the right engine and fonts quickly.

Engines:
- Default: pdflatex (fast, stable, good for Latin scripts, no custom system fonts)
- Switch to xelatex (or lualatex) if: custom brand fonts, non-Latin scripts, RTL, or advanced font features

Font choices:
- pdflatex: stick to defaults or use package-level fonts that ship with TeX Live (e.g., mathpazo, lmodern, newtxtext/newtxmath)
- xelatex: use fontspec, e.g., \setmainfont{Inter} or \setmainfont{Helvetica Neue}; ensure font installed on system

Micro-typography:
- Include microtype (pdflatex-friendly) for nicer spacing unless user forbids extra packages

Fallback guidance:
- If user supplies a font name and compilation fails, fall back to a bundled font or pdflatex-safe default and warn the user
