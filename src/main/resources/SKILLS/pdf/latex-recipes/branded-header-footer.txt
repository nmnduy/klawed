Goal: quick brandable header/footer without heavy dependencies.

Recommended packages:
- fancyhdr for header/footer
- xcolor for brand colors
- lastpage for page X / Y
- graphicx only if user provides a logo; otherwise omit to stay light

Header options:
- Left: Business name (bold), Address/email/phone in smaller text
- Right: Invoice label + number
- Add a thin accent rule: \color{Primary}{\rule{\textwidth}{0.6pt}} below header band

Footer options:
- Center: \thepage / \pageref{LastPage}
- Optional: short support message or payment reminder

Colors:
- \definecolor{Primary}{HTML}{1F4B99} (example) — ask user for HEX/brand colors
- Use \rowcolors or header band shading with Primary!10 for subtle branding

Logo placeholder (if provided):
- Include graphicx and use a small box: \includegraphics[height=1.1cm]{logo.png}
- Keep optional; avoid compile failure if logo missing by gating with user confirmation

Notes:
- Keep to pdflatex-compatible defaults; if user wants custom fonts, switch to xelatex with fontspec.
