Goal: robust line-items and totals layout.

Packages: tabularx, booktabs, array; optional: xcolor for row shading; siunitx if you need decimal alignment (optional, keep off by default for speed).

Line items table pattern:
- Column spec: {@{} X r r r @{}} for Description | Qty | Unit Price | Line Total
- Header: use \toprule/\midrule/\bottomrule from booktabs
- Row striping: \rowcolors{2}{gray!6}{white} if desired
- Add/remove item rows by duplicating the pattern; keep placeholders like {{LINE_1_DESCRIPTION}}

Totals block:
- Small tabular with right alignment: Subtotal, Tax, Discount, Shipping, then bold Total Due
- Place a thin rule above totals for separation

Optional extras:
- Tax columns: add a column for Tax % or Tax Amount as needed
- Currency: keep placeholders raw ({{CURRENCY}}) and avoid formatting unless user instructs

Multi-page tables:
- If many items, consider longtable; otherwise keep simple tabularx for speed

TROUBLESHOOTING TABULAR ERRORS:
===============================
Common compilation errors and fixes:

1. "Misplaced \cr" error:
   - Check column specifications: `@{\extracolsep{\fill}}` (SINGLE backslash)
   - Never split column specs across lines
   - Ensure matching `&` and `\\` in each row

2. Column alignment issues:
   - `l` = left, `c` = center, `r` = right, `X` = flexible width (tabularx)
   - `@{}` removes column spacing, `@{ }` adds space

3. Row coloring errors:
   - `\rowcolors{2}{gray!6}{white}` (start row, odd color, even color)
   - Must be placed BEFORE `\begin{tabular}`

4. Testing: ALWAYS compile after adding/changing tabular:
   ```bash
   pdflatex -interaction=nonstopmode -halt-on-error template.tex
   ```
   Check .log file for specific tabular errors.
